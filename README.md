# Isle CTE Website

## Publish with GitHub Pages
1. Create a new GitHub repository such as `isle-cte`.
2. With GitHub Free, use a Public repository for Pages.
3. Upload everything inside this folder to the repository.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose `main` and `/ (root)`, then Save.

## Weekly updates
Normally edit only `js/schedule-data.js`.
Change the week label, Monday-Friday activities, notebook expectations, and Coming Next.
Commit the change and the website updates from the same data on the homepage, This Week page, and each course page.

## Important
Keep grades, student-specific information, assignment submissions, and private course materials in Google Classroom.
