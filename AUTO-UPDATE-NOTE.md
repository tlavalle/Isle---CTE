# About the Visual Editor

GitHub Pages is a static website, so a public page cannot safely commit changes to your GitHub repository without authentication.

For that reason, the visual editor generates and copies the schedule. The safest one-step weekly workflow is the direct GitHub edit page for `js/schedule-data.js`.

A future version could use a GitHub Action plus an authenticated form, but the current version intentionally avoids putting credentials or write access in the public website.
