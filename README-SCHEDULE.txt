ISLE CTE WEEKLY SCHEDULE — QUICK START

Your website already builds its schedule automatically.

EASIEST WEEKLY METHOD
1. Open js/schedule-data.js on GitHub.
2. Click the pencil icon.
3. Change the week dates.
4. Change Monday-Friday under each class.
5. Click Commit changes.

VISUAL EDITOR
Open schedule-editor.html from the website branch preview, fill in the boxes, and click Generate Schedule / Copy Schedule.

QUARTER CHANGE
Set active: true for the class currently running.
Set active: false for a class that is not running.

The homepage, This Week page, and class pages all use the same schedule data automatically.
